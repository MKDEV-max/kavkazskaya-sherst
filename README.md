# Кавказская шерсть — сайт производителя шерсти и пряжи

B2B-сайт: мытая шерсть, топс и шерстяная пряжа из шерсти дагестанского мериноса.
Заказ — по заявке: КП и счёт на email, оплата по безналичному расчёту.

Сайт: https://mkdev-max.github.io/kavkazskaya-sherst/

## Что заполнить перед запуском

Все данные компании — в одном файле **`js/config.js`**. Пустое поле = на сайте ничего не показывается
(никаких заглушек). В консоли браузера сайт подсказывает, что ещё не заполнено.

1. `contacts.phone`, `contacts.email` — без них клиенту некуда написать.
2. `form.accessKey` — ключ Web3Forms (https://web3forms.com → почта отдела продаж → ключ придёт письмом).
   Пока ключа нет, форма **не делает вид, что заявка ушла**: она собирает текст заявки и предлагает
   отправить его по email / WhatsApp / Telegram из `contacts`.
3. `company.*` — юрлицо, ИНН, ОГРН(ИП), адреса. Появятся в подвале, на странице «Контакты» и в политике.
4. `terms.*` — сроки изготовления и отгрузки, упаковка.
5. `documents` — реальные документы (PDF в `assets/docs/`) с датой и тем, что они подтверждают.
6. `productionPhotos` — реальные фото производства (в `assets/production/`) для этапов на странице «О производстве».

Ассортимент — **`js/products.js`**. Неизвестные характеристики — `null`, они не показываются.
Фильтры каталога строятся сами: группа (например «Номер нити») появляется, когда у позиций
категории есть хотя бы два разных значения.

Фото с пометкой `stock: true` — иллюстрации с фотостока (на сайте подписаны «Иллюстрация»).
Замените их реальными фото продукции и поставьте `stock: false`.

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `catalog.html`, `about.html`, `delivery.html`, `contacts.html`, `privacy.html`, `404.html` | готовые страницы (собираются, не править вручную) |
| `src/` | исходники: `layout.html` (head, SEO), `header.html`, `footer.html`, `dialogs.html`, `icons.svg`, `pages/*.html` |
| `tools/build.py` | сборка страниц и `sitemap.xml`: `python tools/build.py` |
| `css/site.css` | стили: дизайн-токены (`--color-*`, `--space-*`, `--radius-*`, `--shadow-*`, `--font-*`, `--container-*`), компоненты, разделы |
| `js/config.js` | контакты, реквизиты, условия, документы, отправка формы |
| `js/products.js` | каталог |
| `js/site.js` | общее: контакты из конфига, меню, FAQ, окна, форма заявки |
| `js/catalog.js` | фильтры, карточки, окно товара, сравнение характеристик |
| `robots.txt`, `sitemap.xml`, `site.webmanifest`, `assets/favicon.svg` | SEO и иконки |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

## Как вносить изменения

- Тексты страниц, шапка, подвал → правьте в `src/`, затем `python tools/build.py`.
- Контакты, условия, документы → только `js/config.js` (пересборка не нужна).
- Товары → `js/products.js` (пересборка не нужна).
- Отправьте изменения в GitHub — через 1–2 минуты сайт обновится.
